# FP3級 学習単語帳

GitHub Pagesで公開できる静的HTML単語帳です。

## 公開方法

1. このフォルダーの `index.html` をGitHubリポジトリのルートにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** で **Deploy from a branch** を選びます。
4. **Branch: main / (root)** を選び **Save** します。
5. 公開URL（通常 `https://<ユーザー名>.github.io/<リポジトリ名>/`）で開きます。
